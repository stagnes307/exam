# 제품 요구사항(PRD)

2단계에서 원문과 1단계 조사·답변을 근거로 작성한다. 기존 PRD·지정 문서를 재사용하고 진행·판단·검증은 활성 계획에 연결한다.

## 사용자와 범위

- 대상 사용자·역할·해결할 문제:
- 본인이 정한 목적·우선순위·이유(미확정은 구분):
- 근거 문서·실제 질문/답변·정정의 경로:
- 입력 자료·출력 규격·필수 제출물:
- 제외 범위·선택 기능·보류한 요구:

- 자료별 업무 의미·중요한 가정·미확정과 그 의존 범위(답변 전체를 계획 전제로 삼지 않음):
- 데이터/조건 변경과 기존 결과의 유효성·실패/복구에 관한 실제 요구:

## 품질과 비교 기준

규칙 준수와 품질을 구분한다. 실제 과제에 맞는 지표를 선택하고 공식 기준이 없는 목표는 본인의 선택과 근거로 표시한다.

| 품질 지표 | 정의·단위·좋아지는 방향 | 선택 이유·근거 | 같은 입력으로 비교할 기준 방법·목표/허용 손실 |
| --- | --- | --- | --- |
| | | | |

- 규칙 준수의 독립 검사·핵심 기대값 근거:
- 비교할 입력·조건·규모와 실행 비용 측정 방법:
- 규모 확대·핵심 조건 변경 시 확인할 정확성/품질/성능:
- 활성 계획 경로(실제 측정·차이·한계 기록):

특정 주제·알고리즘·Worker를 필수로 가정하지 않는다. 해당 없는 비교는 이유를 남긴다. 요구 변경은 근거와 영향받는 ID를 계획에 기록하고 이 문서에 반영한다. 완료 여부를 중복 관리하지 않는다.
